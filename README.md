This repository held the old **Windows .exe** builds of the editor, up to the 10.x versions.

**Please use the online editor instead.** It is free and needs no download or install. It works on phone and desktop, comes in 6 languages and is always up to date with the newest game patch. It also has every feature this version had, plus much more.

## Why the move?
Some antivirus programs flagged the self-built .exe as suspicious. That was a false alarm, but it scared people for no reason. A web page can't trigger that, works on every system including phones, and updates itself.
