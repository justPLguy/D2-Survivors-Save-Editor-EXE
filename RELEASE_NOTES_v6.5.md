# D2 Survivors Save Editor v6.5 — Release Notes

## What's New
- Added support for editing modifiers on items stored in character inventory.
- Preserved equipped item and mercenary equipment editing.
- Gold editing and existing save functionality remain unchanged.

## Testing
- Inventory modifier changes were verified in-game using the Python version.
- The packaged EXE must be launched and tested on Windows before release.

## Important
Always back up your original save before making modifications.
This is an unofficial community-made tool.
